## 🌟 Highlights

- **3-Theme Material Architecture**: Switch dynamically between **Apple Frosted Glass** (`backdrop-blur-xl`), **Tactile Claymorphism**, and **Sleek Neumorphism**.
- **Global Persistent Timer**: The focus HUD survives route changes, persisting study time in background contexts with optional optical presence detection.
- **Interactive DAG MindMap**: Powered by `@xyflow/react` for intuitive topological learning paths.
- **Embedded DevOps Terminal**: Real-time interactive shell via Xterm.js connecting to the backend PTY bridge.
- **Theme-Adaptive Notes**: Markdown note taking workspace optimized for both dark and light modes.

## 🚀 Quick Development

```bash
# Install dependencies
npm install

# Run Vite development server
npm run dev

# Production build
npm run build
```

The application runs by default on **http://localhost:5173**.
