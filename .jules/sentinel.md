## 2025-03-01 - DOMPurify usage for XSS mitigation in StreamingMessage
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was present in the `StreamingMessage` React component due to the unsafe use of `dangerouslySetInnerHTML`. The component took AI-generated or user-controlled text, parsed it as Markdown (via string replacement), and injected it directly into the DOM without sanitization.
**Learning:** React's `dangerouslySetInnerHTML` is aptly named—it bypasses React's built-in escaping mechanisms. If untrusted input is passed to it, malicious scripts can execute in the victim's browser. While custom markdown renderers can parse text, they do not inherently strip malicious HTML tags or script attributes.
**Prevention:** Always use a reputable sanitization library, such as `DOMPurify`, to sanitize any HTML string before passing it to `dangerouslySetInnerHTML`. In this case, `DOMPurify.sanitize(renderMarkdown(displayedText))` ensures that only safe, expected HTML elements and attributes are rendered, effectively neutralizing XSS payloads.
