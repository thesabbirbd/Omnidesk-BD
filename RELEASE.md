# Release Information

[![Latest Release](https://img.shields.io/github/v/release/thesabbirbd/Omnidesk-BD?style=for-the-badge&color=brightgreen)](https://github.com/thesabbirbd/Omnidesk-BD/releases/latest)

## Release Channels
- **Stable:** Officially tested and signed releases via GitHub Releases.
- **Nightly:** Automated builds triggered by pushes to main (Drafts).

## Artifacts Available
- Windows: `setup.exe`, `.msi`
- Linux: `.AppImage`, `.deb`, `.rpm`
- Android: `.apk`, `.aab`

All desktop binaries support secure, cryptographically signed in-app updates. Check `QA_TEST_MATRIX.md` for quality assurance criteria.
